# Codex chats come back

- **After an update or a restart, Codex chats reopen too.** They used to be tried before Codex's own list of chats had loaded, so they looked gone. Now it waits for Codex first, and anything that still can't reopen gets a second try a moment later.
- **If a chat can't reopen, the log says why.**
- **Test versions:** with Get test versions first on, a newer stable version is still found on Windows.
